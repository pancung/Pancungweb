Web Pan Čung — klon teya.com pro finančního poradce

Kompletní zadání, design systém, architektura a stav projektu. Dokument slouží k přenesení projektu jinam (jiný tým / nástroj / archiv).

1. Původní zadání

Vytvořit klon webu teya.com/cz — pixel-perfect co do struktury, layoutu, typografie a animací — adaptovaný na osobní brand Pana Čunga, poradce v oblasti životního pojištění a wealth managementu pro vietnamskou komunitu v ČR. Web má působit jako prémiový wealth-management brand, ne jako „obchod s kalkulačkami“.

Klíčové požadavky

  1. Homepage = 1:1 zrcadlo anglické verze Teya.com — stejné pořadí sekcí, chování při scrollu i animace.
  2. Bento grid na homepage — karty se dají rozkliknout a otevřou detail modal přesně jako Teya „Automate your bills“ (obsah, kroky, FAQ, CTA; žádné přesměrování).
  3. 3D scrollovací karta: přední strana celá zlatá jen s textem „ZLATÁ PRAVIDLA FINANČNÍ SVOBODY“ (+ logo/podpis). Pravidla se odhalí teprve při scrollu dolů — karta „letí“ do svého slotu a otočí se o 180°. Animace frame-perfect podle teya.com.
  4. Kalkulačky přímo na webu — integrované v sekci, žádné přesměrování na externí weby.
  5. Barvy: khaki zelená + zlatá.
  6. Font zachovat jako na Teyi (Figtree + script/display doplňky).
  7. Dvojjazyčnost CS / VI včetně vietnamské diakritiky a vhodných fontů.
  8. Obsah lidský a osobní (Pan Čung v první osobě, chat s poradcem, papírový finanční plán, O mně) — ne korporátní.
  9. Rezervace schůzky přes pancungradi.simplybook.it, poptávky na backend POST /api/leads.
  10. Komunikace s agentem v češtině.

5. Technický stack a architektura

Frontend React + Tailwind CSS + Framer Motion 13 + Radix (shadcn/ui) + React Router
Backend FastAPI (Python), všechny routy s prefixem /api
DB MongoDB přes MONGO_URL z .env
Config frontend volá API přes process.env.REACT_APP_BACKEND_URL

6. Technické poznámky a pasti

Animace zlaté karty jsou proměřené. Transform matice v CardIntro.jsx byly odečteny po 50 px scrollu přímo z teya.com (1920×800). Timeline: script texty ±150/+40 px → 0/−40 px (horní hrana sekce 20 vh → dolní hrana 0); karta po překročení středu 53 vh během 1 vh scrollu sjede po naměřené křivce do slotu #gold-card-landing v RulesPanel.jsx a otočí se o 180°. Tyto hodnoty neměnit, pokud si zadavatel nestěžuje na animaci.
  • framer-motion 13: useScroll + useTransform používá nativní ViewTimeline → ve sticky sekci nefunguje. Řešeno vlastním hookem useScrollMap (JS mapování) — pro sticky scroll animace používat vždy ten.
  • LineChart: při změně počtu bodů se path remountuje (key=n, initial=false) → žádné „undefined path“ warningy; refLine pro cílovou linku.
  • Navbar mění téma podle sekce pod ním (data-nav="dark", elementFromPoint).
  • Animace: WordReveal, TiltCard, ScrollProgress, shine na tlačítkách, animované bary/grafy, AnimatePresence u kalkulaček, page fade.
  • data-testid na všech interaktivních prvcích (kebab-case, unikátní).
